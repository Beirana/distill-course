# 学生实验指南：500条教学示范蒸馏

## 实验目标

使用教师模型生成数学解答，经筛选后用500条示范训练小型学生模型；在相同问题和推理条件下比较训练前后的输出。完整命令见根目录README.md。

教师为Qwen2.5-7B-Instruct，学生为Qwen2.5-0.5B-Instruct。学生已经经过通用指令训练，本实验在此基础上学习当前任务。训练采用LoRA与教师文本监督，不使用教师和学生概率分布之间的KL损失。

## 每一步应看什么

| 阶段 | 输入与动作 | 需要观察的结果 |
|---|---|---|
| 环境 | 检查Python、PyTorch、GPU，按需安装组件 | 实际版本、GPU是否可用；已准备镜像无需重复安装 |
| 数据 | 从Numina的gsm8k来源筛选题目，用参考答案核对；保留开发/测试划分 | 候选题、开发题、测试题各自用途，不把测试题用于训练 |
| 教师生成 | 教师解题，检查结束状态、最终数值、格式和长度 | 实际保留500条，不是只请求生成500次；人工阅读部分推理过程 |
| 基线 | 原始Instruct学生回答开发题 | 保存原始输出及正确率、格式、正常结束情况 |
| LoRA训练 | 对合格示范训练少量增量参数 | loss、实际步数、训练用时、adapter文件；loss不是准确率 |
| 导出 | 将adapter与对应学生基座合并 | 模型可重新加载，能正常生成；不能把adapter配给另一个基座 |
| 评测 | 训练后模型回答同一批题，使用相同解码参数 | 正常结束、格式合规和答案正确分别统计，并记录速度与显存 |

新实例首次下载模型前，需先重建数据盘目录（命令见README路径A开头）：镜像只保存系统盘，`/root/distill-work` 指向数据盘的 models/cache 符号链接在新实例上悬空，跳过此步 download-models 会报 `FileNotFoundError`。

## 两种数据路径

- 重新生成：按README路径A从候选题生成500条，保留生成和拒绝记录。
- 使用提供的材料：按README路径B导入已准备题目或500条示范。实验报告应写明使用了已有数据，不应声称本次重新生成。

随附test.jsonl含自动评测所需参考答案，是教学用公开评测材料，不是保密考试题库。完成开发集验证、固定配置后再评测；不要根据测试答案选择训练数据或调整参数。

## 如何理解结果

`before`是训练前Instruct，`student`是训练后导出模型。主协议分数要求末行解析的数值正确且模型正常结束；格式合规率单独统计。解析器可以识别Answer、boxed、####或纯数值末行，不能把主分数误称为严格Answer格式正确率。

输出更短会影响总耗时。批量吞吐量不是单题响应时间；整卡显存包含推理缓存，不等于模型权重大小。训练前后学生参数规模相同，不能预设训练后必然更快或更省显存。

## 实验报告建议

记录环境和GPU、模型/数据版本、实际命令、训练参数与耗时；列出前后指标并附至少一例正确输出和一例错误输出。说明是否使用预备数据、遇到的错误及修复方法。推理过程应人工抽查，不能仅凭最终答案一致断言所有步骤都正确。

代码执行遇错先查看日志，不覆盖已有run；需要重试时使用新的run标识。可按《AI辅助实验说明.md》使用AI协助，但要核实它报告的文件与实际输出。
