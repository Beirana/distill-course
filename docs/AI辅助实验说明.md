# AI辅助实验说明

可以手工按README逐步执行，也可以将下述任务交给能够访问你实验实例的AI助手。

> 请先读取当前目录README.md、docs/学生实验指南.md及configs/course.json，帮助我完成500条数学示范蒸馏实验。先检查当前环境、GPU和磁盘；已有可用环境就复用，不重复安装Python或PyTorch。缺少依赖时先查看安装计划，优先兼容的预编译wheel。
>
> 默认教师Qwen2.5-7B-Instruct，学生Qwen2.5-0.5B-Instruct。按README完成小规模检查、教师数据生成、训练前基线、LoRA训练、导出和同协议评测。若使用materials中已准备的数据，请在报告中说明；不要把导入数据说成现场生成。
>
> 每阶段简要解释输入、动作、输出和验证方法。工程问题可以调查并小规模修复，记录修改；不要为了提高成绩静默更换模型、数据或评分。保留原始输出、日志、版本和哈希，不覆盖旧run，不根据测试结果反复调参。
>
> 若推理进程没有正常退出，检查本次运行的进程记录，不通过广泛匹配进程名清理其他任务。失败时说明原因和下一步，不伪造成功。最后给出实际命令、结果表、文件位置及仍未完成的事项。

将AI建议与终端输出对照，确认模型、数据和结果属于同一个run。不要向AI提供与实验无关的个人账号、密钥或其他人的数据。
